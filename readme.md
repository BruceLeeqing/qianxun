# QianXun (千寻)

An AI-powered translation and cross-border chat application built with React Native.

## 🚀 Current Status

QianXun already provides core instant messaging capabilities:

- **Text Chat**: Real-time one-on-one and group text messaging.
- **Voice Chat Room**: Live audio rooms for multi-user voice communication.

The backend services are currently deployed on a cloud server located in **Frankfurt, Germany**, ensuring stable connectivity for cross-border usage.

## 🔮 What's Next

We are actively integrating AI-driven translation features to break down language barriers in real-time conversations, making global communication seamless and natural.

## 🛠 Tech Stack

- **Frontend**: React Native (Single Page Application architecture)
- **Backend**: Go (Golang) with WebSocket support for real-time features
- **Deployment**: Cloud server in Frankfurt

## 📄 About

QianXun aims to connect people across the world by combining reliable messaging with intelligent translation. Stay tuned for upcoming releases!
